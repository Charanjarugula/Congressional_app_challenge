# README banner

`courtly-banner.png` is the 1600 × 560 export of the editable [Brand / README banner in Figma](https://www.figma.com/design/LR6Kq67WXL07ixTesgCwvC/Courtly?node-id=99-6).

The design uses Courtly’s blue, deep blue, tennis lime, and white, with editable text and vector court artwork. Update the Figma frame and export it at 1× to replace this asset. The older app screenshots have been removed.
